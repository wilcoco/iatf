# IATF 16949 관리항목 정의서

## 1. 분석 개요

### 분석 대상 문서
1. 개발품질팀 문서관리 목록 (20개 카테고리, 98개 문서)
2. 설비 일상점검표 (22개 설비별 시트)
3. 성과지표(KPI) 관리표 (28개 지표)
4. 검사체크시트 (수입/출하/정기)
5. 자격인증 문서 (검사원, 내부심사원)
6. 시험성적서 양식
